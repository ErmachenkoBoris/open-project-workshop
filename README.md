# Код есть. А деньги?

Статический React-практикум для воркшопа в Ярославле. Два блока: выбрать пет-проект и обсудить его в паре, затем оценить экономику месяца с платным трафиком.

## Запуск

```sh
npm ci
npm run dev
npm run build
```

Для публикации на GitHub Pages используйте ветку `main` и источник **GitHub Actions** в **Settings → Pages**. Workflow собирает Vite в `dist/`. На опубликованной странице кнопка «QR для воркшопа» показывает QR текущего адреса и позволяет скачать PNG. Ответы хранятся в localStorage на устройстве участника.

## Формулы

- Клики = рекламный бюджет ÷ цена клика.
- Целевые действия = клики × конверсия в первое целевое действие.
- Выручка = целевые действия × выручка с одного действия. Для подписки берём только первый месяц. Для комиссии используем сумму сделки × ставку.
- Результат = выручка − реклама − постоянные расходы − переменные расходы на действие.
- Стоимость привлечения = цена клика ÷ конверсия.
- Бюджет для выхода в ноль = постоянные расходы ÷ (маржа с действия − стоимость привлечения) × стоимость привлечения. Формула применяется при положительной разнице между маржой и стоимостью привлечения.

Модель предполагает, что цена клика и конверсия не меняются с бюджетом. Итоги показывают ожидаемые значения, поэтому количество клиентов может быть дробным.
